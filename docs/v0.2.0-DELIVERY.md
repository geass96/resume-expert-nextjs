## 本轮补丁
- 版本比较升级为字段和经历项目级差异：新增/删除/修改明确区分；工作/项目 bullet 使用 LCS 对齐，避免前面插入一句后导致其他全部误判；无需发送材料到大模型。
- 增加 IndexedDB 草稿缓存：同一个浏览器中分析输入、草稿和人工决策可在刷新后恢复，保存到浏览器本地；退出登录时删除本地草稿。IndexedDB 并不是服务器历史版本备份，不保证浏览器清理后仍存在。
- 历史版本保存时岗位名可直接沿用输入材料的目标岗位。
- 加入纯函数单元测试、隔离生产构建与登录 API 测试、桌面 Edge 浏览器“编辑—刷新—恢复—定稿—退出”回归。
