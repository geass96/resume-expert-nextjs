## 安全默认值与源站风险

本版默认使用单用户共享限流桶，忽略请求者提交的 Cloudflare 和转发 IP 头。仅在管理员验证源站不能绕过 Cloudflare 后，才可以显式设置 `RESUME_TRUST_CLOUDFLARE_IP=true` 按可信客户端 IP 区分。

默认限流仍是进程内计数，重启后清零；多实例或分布式滥用需要另行设计。开启可信头开关本身不提供源站防护。

2026-10-20 的只读核查确认简历站点可从源站直接访问，应用密码登录仍然生效。该网络问题没有在本轮修复。主机同机运行 REALITY，任何源站隔离方案必须局限到简历站点并同时验证站点可用、源站直连被拒、REALITY 可用，不能对整机 443 套通用白名单。

## 数据兼容与回滚

- 本轮没有数据库 Schema 迁移，也不改写已有历史快照。
- 旧决策记录没有 beforeText/applied/beforeProposalId 时保留读取兼容；不明的撤销来源按冲突处理。
- 旧版本若已存在岗位/JD 错配，本轮不会批量修改历史。新保存会使用一致的目标信息，恢复时以持久化岗位为准。
- 回滚代码不会删除新建的岗位 V1 或恢复已经发生的用户编辑；上线前仍应进行在线备份并保留旧发布目录。
- 断开授权会先撤销应用本地使用能力；远端撤销失败仍会报告 revoked=false，按既有提示到账号设置处理。
