# 知识卡片

左侧“历史与练习 → 知识卡片”提供48张核心融合卡，涵盖需求与价值、Prompt与上下文、工作流与Agent、RAG与数据、Skill与执行控制、评测与迭代、PRD与用户体验、边界与面试表达。未分析简历、未配置模型也可使用。

先口述，再翻答案；卡片包含要点、易错点、项目迁移练习和相关课程/题库条目标识。课程观点、案例参数与实践补充分开理解，归纳置信度为中；不提供实时模型价格或排名。内容是独立重写的核心学习卡，不是原题库全文或完整课程资料。

## 使用与数据

- 主题、搜索、到期与薄弱筛选，随机选卡；聚焦卡片后支持空格、方向键及1/2/3评分。
- 项目回答点击保存或在评分时一起保存。切换卡片或工作台模块保留未保存草稿；关闭/刷新页面会提示未保存内容。
- 评分、下次复习时间和项目回答保存到现有SQLite，其他设备登录同一服务后刷新读取。
- 默认忘了10分钟、模糊1天；连续记住依次1/3/7/14/30天。这是简单计划，不是经过个性化校准的记忆模型。
- 支持JSON进度导出/导入，与原离线版`ai-pm-recall-v1`兼容。导入是完整替换，需明确确认，建议先导出当前记录；非法字段整体拒绝。浏览器不能自动读取其他本地HTML的进度，需在离线版导出后选择文件。
- 支持导出纯卡片Markdown；不混入私人项目回答。

## 实现与安全边界

卡片位于`src/data/knowledge-cards.json`，只包含重写内容及来源标识，不含原课程正文、逐字摘录、本机路径或个人进度。进度表`knowledge_card_progress`及版本表`knowledge_card_meta`复用`resume-expert.sqlite`，纳入现有数据库备份，无需新服务和第三方存储。

`GET /api/knowledge-cards`需现有拥有者登录；`PATCH /api/knowledge-cards/[id]`和`PUT /api/knowledge-cards`同时检查来源。全局revision防止旧页面覆盖新记录；冲突返回409，刷新后可重试且客户端保留草稿。导入先全量验证，再在事务中替换；错误不清空数据。页面无模型调用。

单拥有者部署沿用现有身份边界，不把个人进度作为公开静态资源。登录失效及保存失败会显示错误，未保存回答不会伪称已同步。备份导出的JSON包含个人回答，应按个人资料保管。

## 验证

单元测试覆盖计划计算、回答保留、数据库重开、并发冲突和非法导入不破坏既有数据；隔离HTTP集成覆盖登录、来源检查、端到端保存、导入和无模型调用。发布前还需执行仓库门禁与浏览器交互验证，具体结果见本次交付。
