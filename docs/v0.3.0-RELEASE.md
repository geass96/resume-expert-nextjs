# Resume Expert v0.3.0 · AI 模拟面试交付说明

## 范围

个人电脑端文字面试，不新增手机端、多用户、在线语音或多 Agent 编排。此前 v0.2.0 的历史简历、人工确认与自我介绍保持不变。

### 主要功能
1. 选择一个已确认保存的 Resume Version，读取其不可变简历快照与所属目标 JD 作为练习上下文。
2. 选择行为面试、项目深挖、AI 产品与业务、HR 综合四类模拟面试。
3. 每场最多 6 轮，首题基于目标岗位/履历/目标 JD，后续问题参考当前答案、面试类型与保存的履历证据动态生成。
4. 每轮按证据可核实程度、岗位相关性、STAR 结构、表达清晰度、数据与证据口径分别给 0–5 分，返回具体优点、改进建议和待补强证据；加权总分按五项等权换算为 0–100。
5. 支持暂停、恢复、结束、回放、历史练习查看、同一目标岗位的两场练习按评分维度对比。
6. 练习与简历版本通过外键绑定；每轮答案和评价存入 /opt/resume-expert/shared/resume-expert.sqlite。已保存简历不会被面试自动修改。
7. 防止重复轮次提交；暂停后不允许继续回答；完成后禁止再次回答。
8. 匿名请求无权访问历史/面试接口；所有写操作校验来源，并限制请求大小与频率。

### 模型与 Mock
- 配置服务端 LLM_API_KEY 且 USE_MOCK_AI 不为 true 时，由 OpenAI 兼容接口按问题、简历、目标 JD、历史回答生成反馈与追问。
- 没有真实模型密钥时使用清晰标注的规则模拟；规则分数不是实际 AI 评分，也不预测录取概率，不能当成真实的候选人评测。
- 未配置模型的生产环境不会在日志、GitHub 或浏览器泄露密钥。
- LLM 完整端到端效果仍待提供有效 API Key 后做实际验证。

### 数据迁移
- Interview API 第一次被访问时，SQLite 建立 interview_sessions 与 interview_turns 两张表，均引用既有 resume_versions。
- 兼容旧有数据库，无需删除或重建历史简历表；发布前须制作 SQLite 在线一致性备份。
- 生产数据库独立于 releases，部署回滚只切换代码，不替换数据库或删除历史练习。
- 现有每日本地备份脚本基于 SQLite backup API，包含新增面试表。
